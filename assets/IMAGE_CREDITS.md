# Créditos das imagens — VerdePasso

As fotografias deste projeto são imagens ilustrativas de portfólio. A foto do ambiente clínico não representa uma unidade real da VerdePasso. As fotos de atendimento são enquadradas sem rostos identificáveis e não implicam endosso dos modelos ou fotógrafos à clínica.

As imagens foram obtidas no Pexels. A licença do Pexels permite uso gratuito em sites e portfólios, inclusive comercial, sem exigir atribuição; os créditos abaixo são incluídos por cortesia. Consulte a [licença do Pexels](https://www.pexels.com/license/) para os termos completos.

## Otimização

As imagens locais foram servidas pela CDN do Pexels com compressão e larguras adequadas ao uso: 1.400 px para o hero, 700 px para os cartões e 1.000 px para a seção da clínica. Os arquivos JPEG somam aproximadamente 337 KiB. O HTML reserva a proporção de cada imagem, carrega o hero com prioridade e usa carregamento tardio para as imagens abaixo da dobra.
